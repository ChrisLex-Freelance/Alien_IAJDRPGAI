# ASSETS

Ce dossier est destiné à recevoir les images du dépôt (PNG/WebP).

Les fichiers images binaires ne peuvent pas être déplacés via l'API utilisée pour cette restructuration.
Déplacez-les manuellement (interface GitHub : glisser-déposer, ou `git mv`) depuis la racine vers `assets/`, par exemple :

- Images de profils métiers (AGENT_DE_CONFORMITE, ATTACHE_SCIENTIFIQUE, etc.) et portraits (Profil-investigateur, Profil-precheur) -> `assets/profils/`
- Images Deep Zenith (propagande) -> `assets/deep-zenith/`
- Autres illustrations (UUID) -> `assets/illustrations/`
