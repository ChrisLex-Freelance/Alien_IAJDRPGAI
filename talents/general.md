# TALENTS GÉNÉRAUX

Talents accessibles à tous les profils.

## TALENTS GÉNÉRAUX

| TALENT | DESCRIPTION |
|---|---|
| **Appétit d’Oiseau** | Réduisez la consommation de nourriture en lançant moins de dés lors des tests de réserve alimentaire. |
| **Artilleur de Vaisseau** | Bonus de +2 aux tests de **Combat à Distance** en tant qu’artilleur dans un vaisseau spatial. |
| **Bons Réflexes** | Piochez deux cartes pour l’initiative et choisissez la meilleure. |
| **Brutal** | Bonus de +2 aux tests de **Combat Rapproché** en échange de sacrifier votre défense. |
| **Cheval de Trait** | Transportez le double de poids sans être encombré. |
| **Commandant de Vaisseau** | Piochez deux cartes pour l’initiative lors des combats spatiaux et choisissez la meilleure. |
| **Conseiller** | Réduisez le **niveau de stress** d’un allié avec un test de **Commandement** une fois par tour. |
| **Deuxième Souffle** | Récupérez 1 point de santé et réduisez le stress en cas de Bris avec un test d’**Endurance**. |
| **Entraînement Gravité Zéro** | Bonus de +2 aux tests de **Mobilité** effectués en apesanteur. |
| **Esprit de Contradiction** | Bonus de +2 aux tests de **Manipulation** pour résister aux ordres ou aux talents des officiers. |
| **Furtif** | Bonus de +2 aux tests de **Mobilité** pour se déplacer sans être repéré. |
| **Garde du Corps** | Subissez une attaque à la place d’un allié proche avec un test de **Mobilité** pour intercepter les dégâts. |
| **Impitoyable** | Donnez un coup de grâce sans faire de test d’**Empathie**, réduisez votre **niveau de stress** d’un point. |
| **Mécano de Vaisseau** | Bonus de +2 en **Machines Lourdes** pour réparer les avaries d’un vaisseau spatial. |
| **Menaçant** | Bonus de +2 en **Manipulation** pour intimider un adversaire avec votre présence physique. |
| **Mitrailleur** | Restez calme en tir automatique et réduisez votre **niveau de stress** d’un point en mode automatique. |
| **Nerfs d’Acier** | Bonus de +2 aux tests de Panique pour garder votre sang-froid. |
| **Poids Mouche** | Utilisez **Agilité** au lieu de **Force** pour bloquer en **Combat Rapproché**. |
| **Réserve Cachée** | Commencez chaque session avec un objet caché, choisi parmi vos possessions raisonnables. |
| **Robuste** | Augmentez votre Santé de 2. |
| **Sommeil Réparateur** | Dormez un Quart sur deux et restez en bonne santé malgré les horaires réduits. |
| **Souffle Calme** | Réduisez la réserve d’air consommée en lançant moins de dés pour les tests. |
| **Spécialiste des Armes** | Bonus de +2 avec une arme spécifique choisie, utilisable plusieurs fois pour des armes différentes. |
| **Spécialiste Extravehiculaire** | Bonus de +2 en **Machines Lourdes** et **Comtech** lors des interventions en extérieur dans l’espace. |
| **Stoïque** | Effectuez des tests d’**Endurance** avec **Esprit** au lieu de **Force**. |
| **Tir Rapide** | Tirez avec un malus de -2 en utilisant une action rapide. |
| **Tueur** | Déclenchez une blessure critique avec un coup dévastateur contre un adversaire à terre. |
| **Vif comme l’Éclair** | Dégainer une arme gratuitement, sans utiliser d’action. |
| **Vigilant** | Bonus de +2 en **Observation** pour détecter des embuscades ou des attaques furtives. |
| **Bidouillage** | Créez un objet temporaire utile à partir de pièces trouvées en consacrant un Tour. |
| **Calme Olympien** | Une fois par session, réduisez de 1D6 votre **niveau de stress** grâce à votre résistance mentale. |
| **Concentration Intense** | Bonus de +2 à une tâche avec une durée de Quart, mais échouez automatiquement si interrompu. |
| **Dresseur** | Forcez un animal à obéir avec un test de **Survie**, utilisable pour les créatures domestiquées ou extraterrestres. |
| **Impérieux** | Transformez un échec en **Commandement** en test de **Manipulation** sans coût supplémentaire. |
| **On Parle la Même Langue** | Réduisez les malus des tests de **Commandement** et **Manipulation** face à une foule hostile. |
| **Précision** | Bonus de +2 en **Machines Lourdes** pour manipuler des objets ou reliques fragiles. |
| **Psychologie de Groupe** | Posez des questions précises sur le comportement collectif avec un test d’**Observation** pour analyser les foules. |

## NOUVEAUX TALENTS

Talents adaptés du supplément fanmade pour Coriolis de Michel Masberg (**WEB OF THE DATA SPIDER**).

| TALENT | DESCRIPTION |
|---|---|
| **Spectre Numérique** | Vous êtes un maître dans l’art de masquer vos empreintes digitales et électroniques, essentiel pour échapper à la surveillance omniprésente des corporations. Que vous infiltriez un réseau de la Weyland-Yutani ou que vous protégiez vos propres données, vous ajoutez +2 à vos tests de **Comtech** pour éviter toute détection. |
| **Profiler** | Vous pouvez utiliser votre compréhension des systèmes pour manipuler les individus. Avec un accès à un terminal, vous pouvez remplacer **Manipulation** par **Comtech** dans des négociations ou intimidations, si vous disposez d’au moins 1D6 minutes de préparation. |
| **Analyse prédictive** | Dans un environnement où la survie dépend des calculs précis, vous pouvez analyser des données brutes pour prédire des événements probables. Ajoutez +2 à vos tests de **Comtech** pour tirer des conclusions stratégiques des données. Les membres de votre équipe peuvent utiliser vos prédictions pour bénéficier de dés bonus s'ils suivent vos directives. |
| **Faussaire Numérique** | Dans un univers où les identités sont contrôlées et les données constamment surveillées, vous savez manipuler les informations. Ajoutez +2 à vos tests de **Comtech** pour altérer des archives numériques, fabriquer de fausses identités ou falsifier des documents officiels. Avec les ressources appropriées, vos créations sont presque indétectables. |

## AJOUTS PERSONNELS

| TALENT | DESCRIPTION |
|---|---|
| **Survivant Né** | Vous avez le don inné de trouver une échappatoire là où d'autres ne voient que la fin. Une fois par séance, vous pouvez relancer un jet raté de **Survie** en situation critique. |
| **Paranoïa Salutaire** | Votre méfiance permanente vous protège des embuscades et des pièges. Ajoutez +2 à vos tests d’**Observation** pour détecter des dangers cachés, tels que des créatures en embuscade ou des dispositifs. |
| **Instinct de Chasseur** | Vous savez traquer votre proie et ne lâchez jamais votre cible. Ajoutez +2 aux tests de **Observation** ou de **Mobilité** pour pister une créature ou un individu. |
| **Sang-Froid Absolu** | Votre calme face au chaos est impressionnant. Lorsque vous subissez un test de Panique, vous pouvez réduire le résultat final de 1D6, minimisant le stress pour vous et vos alliés proches. |
| **Instinct de Dernière Minute** | Votre intuition vous permet de réagir juste avant que le pire ne se produise. Une fois par séance, vous pouvez éviter une catastrophe imminente (comme une explosion ou une attaque surprise) en réussissant un test de **Observation**. |
| **Réparations Express** | Vous êtes capable de remettre en état des systèmes endommagés dans des situations critiques. Réduisez de moitié le temps nécessaire pour réparer une infrastructure grâce à vos tests de **Comtech** ou **Machines Lourdes**. |
| **Maître des Ventilations** | Vous savez parfaitement vous déplacer dans des espaces confinés comme les conduits d’aération ou les recoins des stations spatiales. Ajoutez +2 à vos tests de **Mobilité** dans des espaces restreints. |
| **Expert des Systèmes ** | Vous avez une compréhension approfondie des systèmes complexes. Ajoutez +2 à vos tests de **Comtech** lorsque vous tentez de pirater, reprogrammer ou désactiver un système. |
| **Sixième Sens** | Vous ressentez les dangers avant même qu’ils ne se manifestent. Une fois par séance, vous pouvez demander à l’Hôte une indication subtile d’un danger à venir ou d’un choix critique à faire. |
| **Récolteur Opportuniste** | Vous êtes doué pour récupérer tout ce qui peut servir. Ajoutez +2 à vos tests de **Survie** pour trouver des ressources (munitions, outils, nourriture) dans des environnements hostiles ou abandonnés. |
| **Spécialiste de la Quarantaine** | Vous savez réagir face aux menaces biologiques. Ajoutez +2 à vos tests de **Survie** ou **Soins Médicaux** pour analyser ou contenir une contamination, qu’elle soit biologique ou chimique. |
