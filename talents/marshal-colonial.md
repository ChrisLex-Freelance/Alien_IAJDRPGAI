# TALENTS — MARSHAL COLONIAL

Talents associés au profil **Marshal Colonial**.

| TALENT | DESCRIPTION |
|---|---|
| **Autorité** | Utilise **Commandement** au lieu de **Manipulation** pour forcer quelqu’un à obéir. |
| **Investigateur** | Pose des questions précises lors d’un test d’**Observation** dans une enquête. |
| **Neutralisation** | Désarme ou neutralise un adversaire sans infliger de dégâts avec un test de **Combat Rapproché**. |
