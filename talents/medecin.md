# TALENTS — MÉDECIN

Talents associés au profil **Médecin**.

| TALENT | DESCRIPTION |
|---|---|
| **Chirurgien de Terrain** | Bonus de +2 aux tests de **Soins Médicaux** pour stabiliser les blessés graves. |
| **Compassion** | Forcez deux tests d’**Empathie**, augmente votre **niveau de stress**. |
| **Présence Apaisante** | Réduit le **niveau de stress** d’un allié à proximité une fois par tour. |
