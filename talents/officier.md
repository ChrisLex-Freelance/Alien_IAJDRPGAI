# TALENTS — OFFICIER

Talents associés au profil **Officier**.

| TALENT | DESCRIPTION |
|---|---|
| **Influence** | Forcez deux tests de **Commandement**, augmente votre **niveau de stress**. |
| **Jouer du Galon** | Utilisez **Commandement** pour forcer des actions spécifiques, mais augmente votre **niveau de stress**. |
| **Officier de Terrain** | Donne des ordres rapides en combat avec **Commandement** sans utiliser une action. |
