# TALENTS — PROLO

Talents associés au profil **Prolo**.

| TALENT | DESCRIPTION |
|---|---|
| **Blasé** | Ignorez une panique ou un dé par séance. |
| **Coriace** | Réduisez les dégâts grâce à un test de **Force** lors d’un combat. |
| **Cran** | Forcez deux tests de **Force**, augmente votre **niveau de stress**. |
